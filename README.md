# Multidomain Ontology for Ubiquitous Learning and Teaching

Ontología de dominio que permite expresar situaciones de aprendizaje ubicuo. Una particularización de esta ontología se emplea en [CHEST](https://chest.gsic.uva.es), [NEST](https://nest.gsic.uva.es) y [MoMoEST](https://momoest.gsic.uva.es). Estas aplicaciones han sido particularizadas a partir de [xEST](https://github.com/gsic-emic/xEST).

Esta ontología se ha desarrollado en el marco de la tesis doctoral de [Pablo García Zarza](https://www.linkedin.com/in/pabgarzar) dentro del grupo de investigación [GSIC-EMIC](https://gsic.uva.es).
